# Security policy

Security reports are accepted for the current 1.x release line and, before the
first tagged release, for `main`.

Report suspected vulnerabilities through [GitHub private vulnerability
reporting](https://github.com/SemiAIFoundry/computation-realization-geometry/security/advisories/new).
Do not open a public issue. If GitHub private reporting is unavailable, use the
[semiAIfoundry contact form](https://semiaifoundry.com/contact/), select
**Privacy, legal, or security** and **Security report**, provide only a
high-level summary and safe return contact, and request a secure follow-up
channel. Do not place exploit details, credentials, private keys, confidential
data, regulated data, or live customer data in the public contact form.

After a secure channel is established, include the affected version or commit,
impact, reproduction steps, and proposed mitigation if known. Please allow
coordinated review before public disclosure. This policy does not create a
warranty, service-level commitment, or support obligation.
