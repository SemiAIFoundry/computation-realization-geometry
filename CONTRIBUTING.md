# Contributing

This repository is a curated research and validation corpus. Semi AI Foundry,
LLC does not accept outside code submissions or pull requests for this corpus.

Public issues may report a reproducibility discrepancy, citation or metadata
correction, provenance problem, or narrowly scoped documentation correction.
Search existing issues first and identify the affected file, version, or
commit. Do not submit confidential, export-controlled, customer, regulated,
employer-restricted, or third-party proprietary material.

Do not report vulnerabilities publicly. Follow [SECURITY.md](SECURITY.md).
Submissions do not transfer ownership and do not create an obligation to
review, incorporate, support, or respond to proposed changes.
